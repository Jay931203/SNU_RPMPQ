# Data Registry

Active CSV files in `results/csv/` and their roles.
Legacy/intermediate files are in `results/csv/_legacy/`.

## Primary Data (Paper Figures)

| CSV | Generated By | Used By | Description |
|-----|-------------|---------|-------------|
| `full_comparison.csv` | `analysis/eval_full_comparison.py` | `generate_paper_figures.py`, **kl_vs_ilp** | All methods (hawq-ilp, nmse-static, nmse-adaptive-opt, etc.) with NMSE, outage, rate at SNR=20 |
| `segment_dp_baselines.csv` | `analysis/segment_dp_baselines.py` | `generate_paper_figures.py`, **fig_segment_dp_all_models**, **fig_cross_arch_outage** | Segment DP results for all 4 models (MT-AE, CLNet, CRNet, CsiNet) |
| `outage_multi_snr_sweep.csv` | `analysis/eval_outage_multi_snr_sweep.py` | `generate_paper_figures.py`, **fig_online_outage** | Multi-SNR outage for segment-dp and hawq-ilp |

### Method Mapping in `full_comparison.csv`

| method | Paper Name | Description |
|--------|-----------|-------------|
| `hawq-ilp` | HAWQ-ILP | Per-layer ILP baseline |
| `nmse-static` | Segment DP | Equal allocation across zeta bins |
| `nmse-adaptive-opt` | Joint DP | Optimized per-bin budget allocation |
| `nmse-adaptive-equal` | Segment DP + zeta | Equal alloc with zeta conditioning |

## RP-MPQ v2 Data

|-----|-------------|
| `rpmpq_v2_collected.csv` | Raw collected metrics per (block, bits, zeta_bin) |

## Budget Allocation / Outage

| CSV | Description |
|-----|-------------|
| `budget_allocation.csv` | Outer budget allocation (NMSE/cos2 objective) |
| `budget_allocation_outage.csv` | Outage-aware budget allocation (greedy) |
| `outage_curves_per_bin.csv` | Per-bin outage curves (gamma=0.95/0.98/0.99) |
| `outage_alloc_baselines.csv` | Joint DP allocation for CLNet, CRNet |
| `outage_alloc_clnet.csv` | CLNet-specific allocation |
| `outage_alloc_crnet.csv` | CRNet-specific allocation |
| `complete_eval_mtae.csv` | MT-AE complete eval (SNR=10/20/30, gamma=0.95/0.98/0.99) |
| `multi_snr_comparison.csv` | Multi-SNR comparison data |
| `joint_dp_comparison.csv` | Joint DP method comparison |
| `joint_dp_policies.csv` | Joint DP selected policies |
| `paper_summary_table.csv` | Summary table for paper |
